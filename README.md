# A comparative study of skill learning for task composition in human-robot collaborative scenarios

Submitted paper for ETFA 2026.

LfD pipeline that compares three motion encoders — **Behavioral Cloning (BC)**, **Dynamic Movement Primitives (DMP)** and **Gaussian Mixture Model + Regression (GMM-GMR)** — on the low-level skills `PICK`, `PLACE`, `POUR` executed on a UFACTORY xArm 6.
